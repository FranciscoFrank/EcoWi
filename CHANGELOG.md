# Changelog

All notable changes to EcoWi are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Station data over the same channel as the EcoFlow app: account sign-in, MQTT certificate, and DELTA 3 protobuf frame decoding (display, runtime and BMS heartbeat messages).
- Official EcoFlow Developer API as an alternative data source (signed REST requests with an MQTT fallback).
- Widgets: **Bar** (5×1, stack-friendly), **Ring** (2×2, 1×1 and a 4×2 variant with the phone's battery) and **Mini** (1×1 / 2×1, also offered for the lock screen).
- Per-widget theme (system / light / dark), background opacity, wallpaper colours and AC / DC display mode (AC first, DC first or alternate).
- Alerts for 15 % and 5 % remaining, fully charged (100 % or the charge limit), charging started, grid lost / restored, and devices plugged into a port.
- Live mode: a persistent connection in a foreground service, shown as an Android 16 Live Update (Now Bar on One UI 8).
- Background refresh every 5 to 60 minutes when live mode is off, and restart after reboot.
- Redesigned Compose UI with Station, Widgets, Alerts and Connection tabs and the "Volt" theme.
- EcoWi neon logo as a vector: adaptive launcher icon, themed (monochrome) icon, status-bar icon and SVG variants, generated by `tools/logo`.
- English as the base language with a full Ukrainian translation and a per-app language setting on Android 13+.
- Open-source documentation: README (English and Ukrainian), contributing guide, code of conduct, security policy, support guide and issue / pull request templates.

### Security

- Account passwords and Developer API keys are encrypted with AES-GCM using a key stored in the Android Keystore.
